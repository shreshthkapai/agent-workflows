# Encode Lessons In Structure

Read `{{RUNTIME_GUIDE}}` for host-specific invocation, agent, model, and capability rules.

When the same failure or correction recurs, consider whether an existing type, lint rule, check, helper, or focused instruction can prevent it at the right layer. Choose the smallest mechanism that addresses the demonstrated pattern and fits the task’s scope; not every one-off mistake needs automation. Keep judgment-based guidance where code cannot enforce the rule. Do not automatically write memory, create skills, delete instructions, or alter global configuration. Durable changes to shared guidance require explicit authorization when they exceed the current assignment. Verify the mechanism against the recurring case it is meant to prevent.
